TP 1: Integrasi Konten Antar Aplikasi Perkantoran

Ilustrasi Grafis: Alur Kerja Object Linking and Embedding (OLE)

[ 📊 PENGOLAH ANGKA (Sumber) ] -> Tabel: Jumlah Siswa 500 -> (Blok Data -> Salin/Copy) -> [ 📄 PENGOLAH KATA (Tujuan) ] -> (Paste Special -> Paste Link -> Objek Worksheet) -> Tampilan Grafik: Terhubung secara dinamis -> [ 🔄 SINKRONISASI OTOMATIS ] Jika angka diubah menjadi "600" pada Pengolah Angka, grafik di dokumen Pengolah Kata langsung berubah menjadi 600 tanpa perlu disalin ulang.

A. Konsep Dasar Integrasi Integrasi aplikasi perkantoran adalah proses menghubungkan data, teks, atau grafik dari satu perangkat lunak ke perangkat lunak lainnya. Dalam lingkungan profesional, pembuatan laporan akhir (pengolah kata) sering kali bersumber dari data perhitungan mentah (pengolah angka).

B. Teknologi Object Linking and Embedding (OLE) OLE memungkinkan sebuah objek (seperti tabel atau grafik) yang disalin tidak hanya sekadar ditempel sebagai gambar mati (Paste biasa), melainkan ditautkan dengan dokumen sumbernya (Paste Link). Jika data pada dokumen sumber diubah, grafik pada dokumen tujuan akan berubah secara otomatis (dinamis).

C. Langkah Teknis Menerapkan Paste Link

  1. Buka aplikasi pengolah angka (misalnya Excel). Buat tabel data inventaris perangkat komputer atau grafik jumlah siswa.
  2. Sorot (blok) tabel atau grafik tersebut, lalu lakukan perintah Salin (Copy / Ctrl + C).
  3. Buka aplikasi pengolah kata (misalnya Word) yang akan menjadi laporan akhir.
  4. Letakkan kursor di area yang diinginkan, klik tanda panah ke bawah pada tombol Paste (Tempel), lalu pilih Paste Special (Tempel Spesial).
  5. Pada kotak dialog yang muncul, pilih opsi Paste Link (Tautkan Tempel).
  6. Pilih format Microsoft Excel Worksheet Object.
  7. Klik OK.

Pengujian: Siswa mengubah angka di file pengolah angka, kemudian menyimpan (Save) file tersebut. Siswa beralih ke file laporan pengolah kata untuk mengamati perubahan otomatis pada tabel/grafik.

TP 2: Otomatisasi Dokumen Massal (Mail Merge)

Ilustrasi Grafis: Mekanisme Cetak Surat Massal

[ 🗃️ SUMBER DATA (Excel) ] [ 📝 DOKUMEN UTAMA (Word) ] Kolom: Nama | Kelas "Kepada Yth. «Nama» di Kelas «Kelas»" Baris: Budi | 10A Baris: Ani | 10B -> [ PROSES MAIL MERGE ] -> [ 🖨️ HASIL CETAK MASAL ] Surat 1: Kepada Yth. Budi di Kelas 10A Surat 2: Kepada Yth. Ani di Kelas 10B

A. Konsep Dasar Mail Merge Mail Merge (Cetak Surat Massal) adalah fitur untuk memproduksi dokumen dalam jumlah banyak (ratusan hingga ribuan) yang memiliki struktur identik, namun memiliki rincian informasi tujuan yang berbeda (seperti nama, alamat, nilai, atau kelas). Fitur ini menghilangkan proses pengetikan manual satu per satu.

B. Komponen Utama Mail Merge Fitur ini membutuhkan dua file yang saling terhubung:

  • Sumber Data (Data Source): Dokumen berisi tabel basis data penerima surat. Umumnya dibuat menggunakan pengolah angka (Excel) agar mudah dikelola. Baris pertama tabel harus berupa nama kolom (Header).
  • Dokumen Utama (Main Document): Dokumen naskah utama yang tidak berubah (misalnya kerangka Surat Panggilan Orang Tua) yang dibuat di pengolah kata (Word).

C. Langkah Teknis Menerapkan Mail Merge

  1. Siapkan Sumber Data: Buka pengolah angka, buat kolom Nama_Siswa, Kelas, dan Nama_Orang_Tua. Isi dengan 5 data contoh. Simpan file dan tutup aplikasi.
  2. Siapkan Dokumen Utama: Buka pengolah kata, ketik format surat resmi undangan wali murid dari SMP-SMA Advent Batam. Kosongkan bagian nama dan kelas yang akan dituju.
  3. Hubungkan Dokumen: Buka tab Mailings, klik Select Recipients, pilih Use an Existing List, lalu cari dan buka file pengolah angka yang dibuat pada langkah 1.
  4. Sisipkan Variabel: Letakkan kursor di posisi "Kepada Yth:", klik Insert Merge Field pada tab Mailings, lalu pilih variabel Nama_Orang_Tua. Lakukan hal yang sama untuk variabel Nama_Siswa dan Kelas pada badan surat.
  5. Pratinjau Hasil: Klik tombol Preview Results untuk melihat perubahan dari tag variabel menjadi data nama asli. Gunakan tanda panah navigasi untuk melihat data ke-1, ke-2, dst.
  6. Selesaikan (Eksekusi): Klik Finish & Merge. Pilih Edit Individual Documents untuk menghasilkan file baru berisi seluruh surat yang sudah jadi dan siap dicetak.

TP 3: Pembuatan Struktur Dokumen Lanjut

Ilustrasi Grafis: Struktur Daftar Isi dan Section Break

[ HIERARKI HEADING ] [ DAFTAR ISI OTOMATIS ] Bab 1 Pendahuluan (Heading 1) ==> Bab 1 Pendahuluan ........ 1 A. Latar Belakang (Heading 2)==> A. Latar Belakang ...... 1 [ FORMAT NOMOR HALAMAN BERBEDA DENGAN SECTION BREAK ] SECTION 1 (Kata Pengantar, Daftar) Nomor: i, ii, iii ===Break==> SECTION 2 (Bab 1, Bab 2, Bab 3) Nomor: 1, 2, 3 (Link to Previous: OFF)

A. Konsep Dasar Struktur Dokumen Laporan panjang (seperti modul ajar, proposal, atau laporan praktikum laboratorium komputer) membutuhkan kerangka yang terstruktur agar mudah dinavigasi. Hal ini melibatkan penggunaan Heading Styles, Daftar Isi otomatis, dan partisi halaman (Section Break).

B. Langkah Teknis Pembuatan Daftar Isi Otomatis

  1. Penerapan Styles: Blok teks yang menjadi judul bab utama (misal: BAB 1 PENDAHULUAN). Pada tab Home, klik format Heading 1. Blok sub-bab (misal: A. Latar Belakang) dan terapkan Heading 2. Lakukan ke seluruh dokumen.
  2. Menyisipkan Tabel: Sediakan satu halaman kosong di bagian awal dokumen untuk meletakkan daftar isi.
  3. Membangun Daftar Isi: Buka tab References, klik Table of Contents, lalu pilih format Automatic Table 1 atau 2.
  4. Memperbarui Daftar: Jika ada perubahan teks judul bab atau pergeseran halaman, pengguna cukup mengklik daftar isi tersebut, pilih Update Table, lalu pilih Update Page Numbers Only (hanya perbarui nomor) atau Update Entire Table (perbarui teks judul dan nomor).

C. Langkah Teknis Manajemen Penomoran Halaman (Section Break) Standar penulisan mengharuskan bagian pengantar (Daftar Isi, Kata Pengantar) menggunakan angka Romawi (i, ii, iii), sedangkan isi laporan menggunakan angka Arab (1, 2, 3).

  1. Letakkan kursor tepat di akhir teks pada halaman pengantar terakhir (misal: di akhir halaman Daftar Isi).
  2. Buka tab Layout, pilih Breaks, klik Next Page (Section Break). Dokumen sekarang terbelah menjadi dua area format independen (Section 1 dan Section 2).
  3. Klik ganda pada area bawah (Footer) di halaman pertama Bab 1 (Section 2).
  4. Di tab navigasi Header & Footer, matikan tombol Link to Previous (tautan ke sebelumnya) agar format terputus dari Section 1.
  5. Buka opsi Page Number, pilih Format Page Numbers.
  6. Ubah format angka menjadi 1, 2, 3... dan pilih opsi Start at 1. Klik OK.

TP 4: Kolaborasi Komputasi Awan (Cloud Computing)

Ilustrasi Grafis: Ekosistem Kolaborasi Serentak

[ ☁️ KOMPUTASI AWAN (Google Drive) ] File: Laporan_Praktikum.docx [ 👁️ VIEWER ] Hanya bisa membaca dan mengunduh. (Tidak bisa ketik) [ 💬 COMMENTER ] Bisa membaca & menambah catatan saran (Teks asli tidak berubah) [ ✏️ EDITOR ] Memiliki kendali penuh (mengetik, menghapus, mengubah tata letak) +---> Akses Serentak (Real-Time Collaboration) <----+ Tampilan kursor beda warna untuk tiap siswa

A. Konsep Komputasi Awan Komputasi awan memindahkan penyimpanan data (melalui Cloud Storage seperti Google Drive) dan pengolahan perangkat lunak (melalui Web Apps seperti Google Docs, Sheets, Slides) dari hardisk lokal (komputer fisik) ke peladen internet. Keuntungannya adalah berkas aman dari kerusakan perangkat keras, dapat diakses dari mana saja, dan mendukung kerja kolaboratif secara serentak.

B. Manajemen Hak Akses (Share Permissions) Saat membagikan dokumen atau folder proyek sekolah, pengguna wajib mengatur hak akses:

  • Viewer (Pelihat): Pengguna yang diberi tautan hanya dapat membaca konten dan mengunduh. Tidak bisa mengubah atau menghapus teks.
  • Commenter (Pemberi Komentar): Pengguna dapat membaca dan menyisipkan catatan atau saran di margin dokumen, namun draf utama tidak berubah sampai saran tersebut disetujui (Approve) oleh Editor.
  • Editor (Penyunting): Pengguna memiliki kendali penuh untuk mengetik, menghapus, menyunting, dan mengatur ulang tata letak dokumen secara langsung.

C. Langkah Teknis Kolaborasi Serentak (Real-time Collaboration)

  1. Satu orang siswa (sebagai pembuat) membuka peladen awan dan membuat file Google Docs baru.
  2. Siswa mengklik tombol Share (Bagikan) di pojok kanan atas.
  3. Masukkan alamat email siswa lain (rekan satu kelompok), atur peran mereka sebagai Editor, lalu klik Kirim.
  4. Seluruh rekan kelompok membuka dokumen tersebut secara bersamaan. Siswa dapat mengetik di paragraf yang berbeda. Sistem akan menampilkan kursor setiap siswa dengan warna dan nama yang berbeda untuk mencegah bentrok pengetikan.
  5. Pemeriksaan Riwayat: Jika ada anggota yang tidak sengaja menghapus seluruh laporan, buka menu File, pilih Version History (Riwayat Versi), dan klik See version history. Pilih rekaman waktu sebelum teks terhapus, lalu klik tombol Restore this version (Pulihkan versi ini) untuk mengembalikan dokumen ke keadaan semula.
